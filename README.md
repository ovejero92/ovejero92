## Sobre mí

Profesional IT con **perfil híbrido**: construyo productos web de punta a punta **y** lidero equipos ágiles desde la idea hasta el MVP en producción.

No solo escribo código: **organizo al equipo que lo escribe**, formo talento y entrego producto real.

Hoy trabajo en **tres frentes** que me hacen valioso para empresas que buscan alguien técnico con visión de producto:

| Rol | Dónde | Qué entrego |
|-----|--------|-------------|
| **PM / Scrum Master** | Innova Lab · Ministerio de Educación GCBA | Equipos de 10–15 personas → apps con impacto social (Mate+, Carpiseñas) hasta MVP y Demo Day |
| **Instructor IT** | Agencia de Habilidades para el Futuro (GCBA) | Formación a escala (~300 adultos/cohorte) + secundaria en programación |
| **Technical Mentor** | CoderHouse | Clases de Desarrollo Web, code reviews y frameworks emergentes |

> **Mi diferencial:** sé el código *y* el proceso. Ideal para roles Full Stack, Tech Lead o Project Manager híbrido.
